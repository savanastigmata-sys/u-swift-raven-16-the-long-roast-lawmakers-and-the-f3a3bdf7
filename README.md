Entrants write one satirical sentence, at most 320 characters, roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF. Entries stay open three days and are judged in six private rounds by a judge model that compares two at a time on bite, aim and freshness. The top ten lines split the reward, with the funniest taking first.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
